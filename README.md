# n8n workflows

n8n workflows I built while learning. Each folder has the workflow JSON, a screenshot and a short README.

| Workflow | What it does |
|---|---|
| [lead-qualification](lead-qualification) | Scores new form submissions with AI, alerts on Telegram, acknowledges by email, logs the result |

To use one: in n8n create a workflow, paste the contents of `workflow.json`, then connect your own credentials. Credentials, emails and IDs have been removed from the exports.
